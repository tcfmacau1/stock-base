已發佈報告與備份

下架後網站不再列出；Git 歷史仍會保留舊版本。正式刪除敏感資料須另外處理 repository 歷史。

首次部署／使用說明
  1. 建立專用 GitHub repository，把 index.html 和 data/reports.json 按目錄結構上載。
  2. Settings → Pages → Deploy from a branch → main / (root)，儲存並等待部署。
  3. 從 GitHub Pages 網址打開本頁。管理頁連線同一 repository，Token 僅需 Contents: Read and write。
  4. 每次上載新 HTML 並發佈，等待 Pages 更新後，讀者按「更新」即可讀到最新報告。
  5. 同股票不同日期保留為歷史版本；同市場、代號及日期會先要求確認替換。

本機直接開啟 HTML 可預覽上載檔案，但公開報告清單需 HTTP 網站載入。草稿只留在當前頁面，重新整理會清除。
